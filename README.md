# readfast

日本語の文章を短い区切りに分け、画面中央で順番に表示する個人用のRSVPリーダー。

## 起動

Node.js 20以上とPython 3を使用します。依存パッケージのインストールは不要です。

```sh
npm start
```

http://127.0.0.1:4173 をブラウザで開いてください。`Intl.Segmenter`に対応した最近のブラウザを使用してください。

## 使い方

1. 文章を貼り付け、「この文章をセット」を押します。
2. 再生ボタンで読み始めます。
3. 速度（文字/分）、表示する最大文字数、句読点での追加待ち時間を調整できます。

Spaceで再生・停止、左右矢印で前後の区切りに移動します。入力欄やボタンにフォーカスがあるときはその標準操作を優先します。タブを離れると自動で停止します。表示文字数を変更すると先頭に戻ります。

入力文章はブラウザのメモリ内だけで扱います。外部API、アクセス解析、外部フォント、永続保存は使いません。再読み込みすると入力は消えます。

単語境界を利用して最大文字数に収まるように区切ります。厳密な文節解析ではありません。表示位置は単純な中央揃えです。読解速度や理解度の向上を保証するものではありません。

## 確認

```sh
npm test
```

このプロジェクトは非公開での個人開発用です。`package.json`の`private`はnpm公開防止の設定であり、GitHubの公開設定とは別です。
