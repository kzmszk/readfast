# readfast

日本語の文章を短い区切りに分け、画面中央で順番に表示する個人用のRSVPリーダー。

**青空文庫から好きな本を選び、全文を読み込んで読めます。** 著者名や作品名で検索し、「読む」を押すだけで速読の準備ができます。速読モードと、通常の文章をスクロールして読む全文モードを切り替えられます。対象は、青空文庫の公式目録に掲載され、同サイト内にHTML/XHTML本文がある任意の作品です。

公開アプリ: https://readfast.kazumasa.workers.dev/

## 起動

Node.js 20以上とPython 3を使用します。依存パッケージのインストールは不要です。

```sh
npm start
```

http://127.0.0.1:4173 をブラウザで開いてください。`Intl.Segmenter`に対応した最近のブラウザを使用してください。

## 使い方

1. 「青空文庫から選ぶ」で好きな作品を検索し、「読む」を押します。自分の文章を貼り付けて「この文章をセット」を押すこともできます。
2. 再生ボタンで読み始めます。
3. 速度（文字/分）、表示文字数の目安、句読点での追加待ち時間を調整できます。

「青空文庫から選ぶ」を開くと、青空文庫の公式目録を検索できます。著者名・作品名・読み仮名・副題を対象に、空白で区切った複数語でも絞り込めます。ひらがな・カタカナ・半角カナを同じ読みとして扱います。文字遣いの絞り込み、著者のショートカット、20件ずつのページ送りがあります。

検索結果の「読む」で本文を取得し、そのまま先頭から再生できる状態にします。速度などの設定は維持します。ルビの読み・編集注・巻末情報を除き、本文と段落を読み込みます。一部の画像外字はUnicodeに変換し、変換できない外字や挿図は代替説明を残します。図版中心の作品では原文も確認してください。作品名・著者・図書カードへのリンクをリーダーに表示します。

対象は公式目録に掲載され、青空文庫内にHTML/XHTML本文がある作品です。外部サイト掲載作品やテキスト版のみの作品は検索対象に含めません。利用条件・底本・入力者などの情報は各作品の図書カードで確認できます。

Spaceで再生・停止、左右矢印で前後の区切りに移動します。入力欄やボタンにフォーカスがあるときはその標準操作を優先します。タブを離れると自動で停止します。表示文字数を変更すると先頭に戻ります。

リーダー上部の「全文で読む」で、再生を止めて通常の文章表示へ切り替えます。段落・空白を保った全文をスクロールでき、速読で読んでいた箇所を強調して表示します。「今の位置へ」で強調箇所に戻れます。「速読」に戻って再生すると同じ箇所から続けられます。全文表示中のSpace・矢印キーは通常のスクロール操作として使えます。

文章を一本の横書きの行として表示し、次の区切りが画面中央へ来るよう左に送ります。各移動の後は必ず静止し、中央の濃い文字と背景で強調した部分を読む時間を確保します。既読部分は同じ行の左側、続きは右側に薄く残り、画面端ではフェードします。現在の強調部分の直前までを、現在行のすぐ上に直近2行分残します。既読テキストは行末へ追記し、行が埋まったら次の行へ進みます。新しい行が必要になったときだけ既存行を上へ送り、すでに表示した文字の横位置や折り返しを変えません。読み戻しでも同じ行配置を復元します。画面幅や文字サイズが変わった場合のみ、その幅に合わせて行を組み直します。横移動が完了した瞬間に、強調部分・過去2行・進捗を一緒に更新します。表示範囲は画面幅に依存せず、同じ行の左側に見える既読部分も含みます。読み戻し・先頭への移動でも、その位置までの文脈に更新されます。

「文字が移動する時間」で80・140・240ミリ秒、または瞬時の切り替えを選べます。移動時間は設定した読書速度に基づく静止時間に追加されます。一時停止すると中央の位置で止まり、読み戻しでは逆方向へ送ります。先頭へ戻る・文章変更・サイズ変更では先頭に即座に戻ります。OSで動きを減らす設定を有効にしている場合は瞬時の切り替えになります。

入力文章はブラウザのメモリ内だけで扱い、サーバーには送信しません。青空文庫の検索語・作品IDは、ローカル版ではPythonサーバー、公開版ではCloudflare Workerへ送信します。検索はそのサーバー内で行い、青空文庫には検索語を送信しません。ローカル版は目録を24時間、本文を直近6作品までメモリにキャッシュします。目録の更新に失敗した場合は保存済みの目録を使い、その旨を画面に表示します。公開版の目録はデプロイ時に更新し、取得した作品はCloudflareのCache APIで最大24時間キャッシュします。アクセス解析・外部フォント・入力文章の永続保存は使いません。再読み込みすると入力は消えます。

ローカルサーバーは127.0.0.1だけで待ち受けます。外部取得先は青空文庫の公式ドメインに限定し、作品IDから目録内のURLを参照します。ファイルを直接開いた場合や通常の静的サーバーでは青空文庫の検索・読込機能を利用できません。ローカルでは `npm start` で起動してください。

[BudouX](https://github.com/google/budoux)の日本語モデルでまとまりを推定し、`Intl.Segmenter`の単語・書記素境界と照合します。助詞や語尾を含むまとまりを優先するため、指定文字数を超えることがあります。句読点では区切り、閉じ括弧を直前の文章に付けます。推定に基づくため、すべての文章で自然な区切りになる保証はありません。表示位置は単純な中央揃えです。読解速度や理解度の向上を保証するものではありません。

日本語モデルとパーサーは`public/vendor/`に同梱され、入力文章を外部に送信しません。Python版の起動には依存パッケージのインストールは不要です。同梱ファイルを再生成する場合は、以下を実行します。

```sh
npm ci
npm run build:segmenter
```

BudouXはApache-2.0ライセンスです。ライセンス全文は`public/vendor/LICENSE-budoux.txt`に含めています。

## Cloudflare Workers

Node.js 22以上、Python 3、CloudflareへのWranglerログインを使用します。`worker/`が公開版のAPI、`public/`が画面です。Pythonはデプロイ時の目録生成に使い、公開先の実行には不要です。

```sh
npm ci
npx wrangler login
npm run deploy
```

`npm run deploy` は公式の青空文庫目録を取得して `.generated/catalog.json` を作成し、画面とWorkerを一緒にデプロイします。作品本文の一括取得は行いません。目録を更新するときも同じコマンドで再デプロイしてください。GitHubへpushしただけでは自動デプロイされません。

Workers実行環境でローカル検証する場合：

```sh
npm run dev:worker
```

http://127.0.0.1:8797 を開きます。従来の `npm start` は引き続きPython版を起動します。APIの検索・本文抽出のテストは `npm test` に含まれます。

GitHubリポジトリは非公開のまま、WorkersのアプリURLは公開されます。ユーザーが入力した文章はデプロイ対象に含みません。`package.json`の`private`はnpm公開防止の設定であり、GitHubやサイトの公開設定とは別です。
